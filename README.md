# CareerMatch UI

A small React + Vite front-end for a resume and job matching project.  
The UI lets users upload a resume file, choose up to three job categories, and see matching job results (mock data for now).  
Later, it will connect to a backend for real scoring and matching.

## Features
- Resume file upload
- Select up to 3 categories
- Category highlighting
- Mock job match output
- Minimal styling and layout

## Tech Stack
- React
- Vite
- TypeScript
- Basic CSS
